# Hel' — листки с задачами

Рабочий репозиторий для составления тематических листков по математике.

## Структура

| Папка | Что внутри |
|---|---|
| `sources/` | Сборники задач, книги, методички — **пул источников**, откуда задачи брать можно |
| `olympiads/` | Варианты олимпиад прошлых лет — тоже пул источников |
| `sheets/` | Готовые листки — **стоп-лист**: задачи отсюда повторно не берём |
| `index/` | Реестр использованных задач (тема, источник, в каком листке засветилась) |

## Как это работает

При составлении нового листка задачи берутся из `sources/` и `olympiads/`,
но сверяются с реестром в `index/` — всё, что уже вошло в листки из `sheets/`,
исключается, чтобы не было дублей.
