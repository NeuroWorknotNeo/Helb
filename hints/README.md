# Подсказки к листкам

Многоступенчатые подсказки (Hint 1, Hint 2, ...) к задачам листков из `sheets/`, на английском.
Структура папок повторяет `sheets/`: подсказки к `sheets/<Тема>/<Листок>.pdf` лежат в
`hints/<Тема>/<Листок>.pdf`, отдельно для классного листка и ДЗ. LaTeX-исходники лежат в
`hints/tex/` с той же структурой, общий преамбул: `hints/tex/hints-preamble.tex`.

Сборка: из папки исходника
`pdflatex -output-directory="<путь к hints/<Тема>>" "<Листок>.tex"` (TeX Live, один проход).

Подсказки к ЛА 1–2, Неравенствам 1 и Trig-2 (классный листок) написаны по готовым решениям.

## Что есть

Из плана IMC (ядро и второй круг): Trig-2, Trig-3, Методы доказательств 1, 2, 3, 4, 6,
Пределы 2, 3, 6, 9, ЛА 1–4, Комбинаторика 1–2.
Сверх плана (были готовы раньше): Функциональные последовательности 1–5, Интегралы 1–5.

## Задачи, где условие, похоже, с ошибкой

Под такой задачей в PDF стоит строка *Note* с объяснением; подсказки следуют исправленной версии.

- **Методы 1, CW 1:** нужно $\|q\alpha\|<1/N$ (расстояние до целого), а не дробная часть.
- **Методы 1, CW 5:** должно быть «существует раскраска без одноцветного $K_k$».
- **Методы 1, HW 1:** для Кронекера нужна независимость $1,\alpha_1,\dots,\alpha_k$ над $\mathbb Q$.
- **Методы 1, HW 2:** точная константа для $n$ точек неизвестна (упаковка кругов в квадрат).
- **Методы 1, HW 5:** утверждение о делимости неверно при нечётном $n$; утверждение про прогрессию в $A+A$ тривиально.
- **Методы 1, HW 6:** среди $n+1$ векторов угол $\le\pi/2$ не обязателен (правильный симплекс); верно для $n+2$.
- **Методы 1, HW 7:** указанной оценки хвоста недостаточно, подсказки используют четвёртый момент.
- **Методы 2, CW 2:** ортогональный базис у симметричной формы требует характеристики $\ne2$.
- **Методы 2, HW 7:** «нельзя доказать индукцией» не является точным утверждением.
- **Методы 3, HW 2:** нужно не меньше 5 точек.
- **Методы 3, HW 8:** неверно для замкнутых интервалов.
- **Методы 3, HW 6:** единственны оба наилучших приближения.
- **Методы 4, CW 2:** у вопроса «какие мультимножества достижимы» нет чистого ответа.
- **Методы 6, HW 2:** условие искажено; доказывается, что попарно касаются не более $2^n$ кубов.
- **Методы 6, HW 5:** $z$ надо читать как показатель степени.
- **Методы 6, HW 10:** приведённое рассуждение по сути верно; подсказки разбирают два необоснованных шага.
- **Пределы 2, CW 3:** рекуррента для $b$ должна начинаться с $n\ge0$.
- **Пределы 2, HW 9:** в оригинале IMC 2022 $p-1$ минут, а не $p$; разобраны обе версии.
- **Пределы 2, HW 11c:** иррациональность $\sum 2/(3^n+1)$ — теорема Борвейна, не олимпиадный уровень.
- **Пределы 3, CW 2:** условие $0<x_0<x_1$ невыполнимо; взято $0<x_0<1$.
- **Пределы 3, CW 4:** конечный ненулевой предел у $x_n^2\ln n$ (он равен 3), а не у $x_n^3\ln n$.
- **Пределы 3, HW 1:** ответ вырожденный; возможно, имелось в виду $\sin^3$.
- **Пределы 3, HW 7:** произведение равно 0; видимо, второй множитель $(n+1)^2/n^2$.
- **Пределы 6, HW 4:** нужна более сильная форма закона распределения простых.
- **Пределы 9, CW 4:** предел не определён однозначно; доказана исправленная формулировка.
- **Пределы 9, HW 6:** условия на $[0,\infty)$ не нужны.
- **Trig-3, CW 3:** при $a_1=a$ условие тривиально; разобраны обе трактовки.
- Ранее помеченные задачи в ЛА, Комбинаторике, Функциональных последовательностях и Интегралах отмечены *Note* в PDF.
