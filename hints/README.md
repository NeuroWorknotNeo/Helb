# Подсказки к листкам

Многоступенчатые подсказки (Hint 1, Hint 2, ...) к задачам листков из `sheets/`, на английском.
Структура папок повторяет `sheets/`: подсказки к `sheets/<Тема>/<Листок>.pdf` лежат в
`hints/<Тема>/<Листок>.pdf`, отдельно для классного листка и ДЗ. LaTeX-исходники лежат в
`hints/tex/` с той же структурой, общий преамбул: `hints/tex/hints-preamble.tex`.

Сборка: из папки исходника
`pdflatex -output-directory="<путь к hints/<Тема>>" "<Листок>.tex"` (TeX Live, один проход).

Подсказки к ЛА 1–2, Неравенствам 1 и Trig-2 (классный листок) написаны по готовым решениям.

## Исправленные условия

16 октября 2026 года в 20 листках исправлены условия с ошибками (исходники в `tex/`, PDF в `sheets/`
пересобраны), подсказки обновлены под новые условия. Методы доказательств 1 (CW 1, 5; HW 1, 2, 5, 6, 7),
2 (CW 2; HW 7), 3 (HW 2, 6, 8), 4 (CW 2; HW 3), 6 (HW 2, 5); Пределы 2 (CW 3; HW 9, 11c), 3 (CW 2, 4;
HW 1, 7), 6 (HW 4), 9 (CW 4); Trig-3 (CW 3); ЛА 1 (HW 8), ЛА 3 (HW 15); Комбинаторика 1 (HW 7);
Функциональные последовательности 2 (HW 10); Интегралы 1 (CW 2).

Строка *Note* осталась в трёх местах, где условие верно и не менялось: Методы 6, HW 10; Пределы 9, HW 6;
Интегралы 3, CW 2.

В новых подсказках строка *Note* отмечает задачи, где условие, по-видимому, содержит ошибку
(например, Комбинаторика 4, HW 10: оценка m/2 + √(m/8) неверна для треугольника). Эти условия пока
не исправлены.
