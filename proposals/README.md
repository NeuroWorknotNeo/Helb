# Новые задачи

Задачи, которых, насколько удалось проверить, не было на олимпиадах, но которые можно предложить.
Каждая задача — частный случай опубликованного результата или леммы из его доказательства и решается
идеями, до которых участник олимпиады может додуматься.

Структура: `<Раздел>/<Раздел> - proposals.pdf` — список задач (условия на английском, без решений),
рядом в той же папке лежат статьи, на которых основаны задачи. Исходники — в `tex/<Раздел>/`.

Задачи составляются по статьям, но решаются классическими методами, изложенными в теорминимумах листков.
Если какой-то задаче всё же нужен факт, которого в листках нет, он выносится в отдельный файл
`<Раздел> - theoretical minimum.pdf` в папке раздела (сейчас такой есть только у Linear Algebra).

Сложность указана как позиция задачи в дне IMC: 1 — простая, 2 — ниже среднего, 3 — средняя,
4 — выше среднего, 5 — сложная.

Статьи берутся только с открытой лицензией (CC BY, CC0 и т. п.), чтобы их можно было выкладывать
в публичный репозиторий. Результат не обязан быть новым: классическую теорему можно взять из статьи
под открытой лицензией, где она сформулирована или передоказана.

Новизна проверялась по пулу олимпиад из `olympiads/` и по листкам из `sheets/`; гарантии, что задача
не встречалась нигде, нет.

## Combinatorics

Задачи в файле упорядочены по сложности. Все 25 задач решены вслепую и проверены так же, как в других
разделах. Две задачи не были решены вслепую и исключены: лог-вогнутость числа подпоследовательностей слова
(Vatter, теорема Чейза) и раскраска отрезков выпуклого многоугольника в звёздные леса (Pach–Saghafian–Schnider).
